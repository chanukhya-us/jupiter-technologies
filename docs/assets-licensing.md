# Jupiter Branding Asset Licensing Notes

## Permission posture
- This project assumes written permission is available for:
  - Jupiter Technologies brand assets (logo, avatar, service icons)
  - Partner/client logos used in this UI package
- Source site references indicate an "All Rights Reserved" notice, so asset reuse should be treated as permission-gated.

## Allowed usage in this repository
- Assets are vendored under `app/static/images/`.
- Assets are consumed only by the internal Flask UI for this project.
- Partner logos are shown only in:
  - Dashboard partner strip
  - Clients page partner grid

## Prohibited usage defaults
- Do not redistribute bundled assets outside this codebase without explicit permission.
- Do not republish partner logos for unrelated marketing material by default.

## Provenance
- Asset source URLs and per-file metadata are tracked in `app/static/images/manifest.json`.
- Attribution details are tracked in `app/static/images/ATTRIBUTION.md`.
